LOCAL ADMIN

商品後台管理

這個後台只在你的電腦上執行，不會公開到 GitHub Pages。你可以在這裡修改網站資訊、商品內容與圖片， 並在儲存後同步推送到前台。

開啟前台

PUBLISH

GitHub 發布設定

你可以在本機使用加密保存的 Token 發布，也可以臨時在這個頁面貼上 Token。 完成設定後，儲存內容即可同步更新前台。

狀態紀錄

SITE META

網站基本資料

這裡的內容會顯示在前台首頁，例如網站名稱、簡介、聯絡方式與幣別。

THEME

版型配色

每個主要區塊都有自己的色盤，調整後會跟網站資料一起儲存與發布。

PRODUCTS

商品資料

左側可切換商品，右側可編輯商品欄位。修改後會先存到本機，再依設定同步發布到前台。

目前沒有尚未同步的變更

SECTIONS

商品段落內容

可新增多個段落，顯示在前台商品詳情頁。

IMAGES

圖片上傳

圖片會上傳到 GitHub Repo 的 assets/products/商品ID/ 目錄，並同步到前台。
